# Microsoft camera reference source

`vendor/Samples/VirtualCamera/` and `vendor/Samples/Shared/` are copied without code changes from Microsoft's [Windows-Camera repository](https://github.com/microsoft/Windows-Camera), commit `626f8b19c5f367602f2e89c6b314573d3776c9df` (retrieved 16 October 2026).

The complete MIT license is retained in `vendor/MICROSOFT-LICENSE.txt`; individual source copyright notices remain intact. `vendor-source-sha256.json` records the copied file hashes. These files are a third-party developer reference and are not bundled into the installed PWA or executed by its service worker.

`MeetingLens.Windows/KsControl.cs` adapts the KS property identifiers, binary layouts and GET/SET pattern from `Samples/WindowsStudio/WindowsStudioSample_WinUI/KsHelper.cs` at the same commit, under that license. The original sample is at <https://github.com/microsoft/Windows-Camera/tree/626f8b19c5f367602f2e89c6b314573d3776c9df/Samples/WindowsStudio>.

MeetingLens's Windows UI, device lifecycle, reports and DirectShow diagnostic utility are maintained separately. The preserved upstream reference keeps Microsoft's sample identity. The new `VirtualCameraProvider/` adapts its source/stream/activation code into a separate MeetingLens provider with its own CLSID; its Microsoft copyright notices and complete MIT license are retained in `VirtualCameraProvider/LICENSE-Microsoft.txt`. MeetingLens adds frame transport, format validation, color conversion, sample scheduling, lifecycle handling and tests. Windows build and acceptance results remain required before release.

The desktop host uses Microsoft's WebView2 SDK (NuGet `Microsoft.Web.WebView2`, pinned in its project) and the installed Microsoft Edge WebView2 Evergreen Runtime. The provider uses Microsoft's C++/WinRT and Windows Implementation Library packages, pinned in its `packages.config`. The build preserves discovered dependency license/notice files under the app's `licenses/` directory. Microsoft's SDK/runtime licensing and redistribution terms apply; the application does not claim ownership of those dependencies. The self-contained .NET distribution includes its runtime notices. Bundled web dependencies and model attribution are also retained under `assets/vendor/` and `assets/models/`.
