SCOPE AND LIMITS
This remains an installable PWA, not a signed Windows installer. Windows packaging, actual pen/tablet tests and Store certification are separate steps.

3D scenes are limited to 200,000 triangles; imports to 30 MB; textures to 12 editable paint layers per mesh. Performance depends on hardware. No promise of million-polygon, lag-free sculpting is made. Generated quad faces are preserved for certain primitives; automatic production retopology is not included. Imported advanced materials, animations and external texture references are not guaranteed to round-trip. Use embedded GLB and validate exports in your destination app.

The included rig is a simple vertical four-bone setup, not AI character autorigging. 3D sketching records strokes on mesh surfaces. It is not Blender Grease Pencil or a complete 3D animation suite. The path tracer is local; a cloud render farm is not connected. The render handoff is an exported GLB plus settings, not a submitted render job.

Team sync shares complete 2D project revisions, not simultaneous brush-stroke merges or 3D scenes. Incoming auto-sync begins only after opening or publishing a shared revision and stops when local edits exist. Shared projects are limited to 30 MB. Local 2D projects retain the 100 MB limit. Hosting, TLS, durable storage, user management and backups are the operator's responsibility; no cloud subscription is included. The shared token is for a small trusted team, not public multi-tenant hosting.

AI image edits remain optional and require the included bridge, a server-side API key, compatible model access and provider charges. AI-generated texture imagery can be applied from the 2D workspace; AI rigging and semantic 3D retopology are not implemented.

Monitor gamut/calibration, tablet pressure resolution, GPU/RAM capacity, drawing gloves, stands and shortcut remotes are hardware properties. The app exposes supported input and shortcuts; it cannot add or certify these hardware capabilities.

EXPORT NOTES
The raster document is 1200 × 900; larger raster exports resample that document. PSD is flattened RGB. The CMYK PDF is a Device-CMYK proof, not ICC-managed PDF/X. SVG retains supported vector paths and text; embedded painting stays raster. The interface is English; document text supports Arabic and English using installed fonts.
