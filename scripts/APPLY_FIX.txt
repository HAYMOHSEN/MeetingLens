RASMORA STUDIO — RELEASE CANDIDATE 5.0.3-rc.1
Pre-release audit: 16 October 2026

STATUS
Ten issue groups were addressed and verified locally. Viewport PNG export
after path tracing still timed out in two software-rendered browser runs.
That workflow remains an open release acceptance blocker. They have not been published
by this audit. Do not submit the current live build as the corrected release.
Read release-audit.html for findings, evidence and remaining Windows tests.

APPLY TO GITHUB PAGES
1. Save any open 2D project and 3D scene. Download a backup of the repository.
2. Extract this ZIP and compare changes with your current repository.
   Base: adb4af2ca04404c75212d6a205246f69f24b70cb (main, 16 October 2026).
3. Upload the package contents to the root of:
   https://github.com/HAYMOHSEN/Rasmora-Studio
   Keep the assets/, licenses/, tests/ and validation/ folder paths intact.
   Replace existing files; do not delete your saved artwork or server data.
4. Commit the changes and wait for GitHub Pages to complete deployment.
5. Save your artwork, then close all Rasmora tabs and installed app windows.
   Reopen the app online. After the offline update finishes, close and reopen
   it once more if needed. The new offline cache is rasmora-studio-v12.
6. On the deployed site, verify New is white, draw/undo/redo, save/reopen a
   project, open an exported PDF, export a short speedpaint, and load 3D.
   Check Privacy, then disconnect the network and reopen the installed app.
