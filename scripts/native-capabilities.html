      SEPARATE WINDOWS COMPANION

      From device support to an informed setup.

      1. Build and run the native Windows utility using the included Windows guide.
      2. Choose a camera, start its preview, and inspect supported Windows Studio Effects before changing them.
      3. Select Export capability report, save the JSON file, and import it above.
      4. If Windows is already applying blur or another enhancement, turn off the duplicate effect inside MeetingLens or your meeting app.

      Eye contact comes from supported Windows hardware, not a browser gaze simulation. Windows chooses acceleration for its effects. The companion is separate from the PWA; the included virtual-camera reference source does not route the PWA canvas to meetings.
